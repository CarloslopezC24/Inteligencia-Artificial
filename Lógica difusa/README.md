# Sistema Experto Difuso - Recomendador de Deportes

Este sistema usa lógica difusa para recomendar un deporte basado en:
- Condición física
- Gusto por la intensidad
- Preferencia social

## Estructura
- `bin/`: ejecutable `main.py`
- `src/`: lógica del sistema experto
- `lib/`: funciones auxiliares
- `out/`: resultados

## Ejecución
```bash
cd bin
python main.py
